# Security

This is an experimental pilot. Anonymous report counts can be forged. Do not base destructive actions or confirmed-outage announcements solely on them.

Report privacy/security concerns through [GitHub private vulnerability reporting](https://github.com/lukeivers/agent-signal-release/security/advisories/new); never include credentials or private tool output in a public issue.

Security fixes target the latest published pilot; there are no maintained older release branches or response-time guarantees. The public pilot is live; source templates remain closed by default for self-hosting. Operator procedures are in [hosting](docs/hosting.md) and the [release checklist](docs/open-source-readiness.md). No authority or execution recommendations are returned by the observation service.
