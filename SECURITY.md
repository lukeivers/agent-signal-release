# Security

This is an experimental pilot. Anonymous report counts can be forged. Do not base destructive actions or confirmed-outage announcements solely on them.

Report privacy/security concerns through [GitHub private vulnerability reporting](https://github.com/lukeivers/agent-signal-release/security/advisories/new); never include credentials or private tool output in a public issue.

Only the current source is supported. The public pilot is live; source templates remain closed by default for self-hosting. Operational changes follow `docs/launch.md`. No authority or execution recommendations are returned by the observation service.
