# Community expectations

Treat participants respectfully. Discuss the work without harassment, discrimination, threats or personal attacks. Do not publish another person's private information, diagnostics or credentials.

Luke Ivers may edit or remove inappropriate content and limit participation to keep the project useful. Report concerns privately through an existing private contact with the maintainer; do not put private allegations into public issues. A verified private contact route must be listed before the public launch. Moderation and support are best effort; this project has no dedicated response team.
